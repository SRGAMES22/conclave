# Conclave

Página de eventos geek: inscrições, ingressos com cupom, check-in e novidades de filmes, séries e jogos.

Marfim de papel, verde-floresta e cartazes em pintura de domínio público.

## Rodar

```bash
npm install
npm run dev
```

Abre em `http://127.0.0.1:8080`.

Cupons de teste: `ARCADE10`, `LORE20`, `FAS15`.
